# Security policy

## Supported versions

Only the latest version on the default branch is currently supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue. Use
GitHub's private vulnerability reporting feature when it is enabled for this
repository, or contact the repository owner privately with:

- A description of the vulnerability and its impact
- Steps to reproduce or a minimal proof of concept
- Affected versions or commit
- Any suggested mitigation

Do not include real credentials, private URLs, production data, or encryption
keys in a report. Allow reasonable time for investigation and remediation
before public disclosure.

API Sentinel is self-hosted software. Operators are responsible for replacing
all development secrets, using HTTPS, restricting database access, preserving
the encryption key, and applying operating-system and dependency updates.
